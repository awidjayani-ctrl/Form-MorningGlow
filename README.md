# Form-MorningGlow

Proyek React + Vite + Tailwind CSS dengan fitur **Interactive Opening Curtains (Tirai Merah)** dan **Hanging Lamp Pull Cord (Lampu Gantung Sakelar Tarik)**.

## Cara Jalankan Proyek:

1. Extract file `Form-MorningGlow.zip`
2. Buka terminal di folder `Form-MorningGlow`
3. Jalankan perintah instalasi dependensi:
   ```bash
   npm install
   ```
4. Jalankan server pengembangan lokal:
   ```bash
   npm run dev
   ```
5. Buka tautan `http://localhost:5173` di browser.
